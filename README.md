# Krithin Kamineni's Personal Portfolio

Personal portfolio website built with Next.js 15, TypeScript, and Tailwind CSS.

## Stack

- **Framework** — Next.js 15 (App Router)
- **Language** — TypeScript
- **Styling** — Tailwind CSS
- **Fonts** — DM Serif Display, DM Sans, JetBrains Mono (Google Fonts)
- **Icons** — Lucide React, Simple Icons

## Features

- Animated hero with typewriter effect, floating circular headshot with spinning amber glow arc
- Cursor-following amber glow that smoothly tracks the mouse
- Auto-scrolling draggable photo strip with lightbox on click
- Shimmer hover effect on dark buttons (left-to-right sweep)
- Separate `/coursework` page with semester-by-semester course breakdown and status badges
- Full-width transparent frosted glass navbar with active section tracking
- Scroll-based fade-in animations throughout
- Contact section with dark background and amber CTA button

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view locally.
